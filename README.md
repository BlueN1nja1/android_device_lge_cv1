# Device Tree for LG Aristo 2 & LG Aristo 2 Plus (cv1)

## NOTICE: THIS TREE IS 80% FUNCTIONAL. THE PHONE BOOTS, SENSORS WORK (INCLUDING AUTO ROTATE), AUDIO WORKS, BLUETOOTH WORKS, ENCRYPTION WORKS OUTTA THE BOX, SELINUX ENFORCING WORKS OUTTA THE BOX, THE SIM CARD IS RECOGNIZED AND DATA IS USABLE, LINEAGE RECOVERY WORKS, FM RADIO WORKS... HOWEVER, THERE ARE A FEW THINGS THAT ARE STILL BEING WORKED ON... PHONE CALLS ARE UNUSABLE, LIVEDISPLAY DOESN'T WORK, CAMERA IS BROKEN (INCLUDING FLASHLIGHT), LOCATION ONLY WORKS OVER THE NETWORK, MAGISK CANNOT BE FLASHED IN LINEAGE RECOVERY.
